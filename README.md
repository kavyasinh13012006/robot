# Robot.com — Interactive Robot Landing Page

A robot-themed frontend concept featuring a landing-page layout and an embedded 3D scene powered by the Spline viewer.

## Tech Stack

- HTML5
- CSS3
- Spline Viewer for the embedded 3D scene
- Local image assets

## Main Elements

- Header and navigation layout
- Hero section with robot-themed branding
- Embedded interactive 3D scene
- Custom styling and local image assets

## Run Locally

1. Clone or download the repository.
2. Open `index.html` in a browser, or use VS Code Live Server.
3. An internet connection is needed to load the remotely hosted Spline viewer and scene.

## Project Focus

This project explores combining a styled frontend layout with an interactive 3D visual. It is a UI concept, not a complete production service.
